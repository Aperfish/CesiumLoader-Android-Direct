# CesiumLoader Android Direct

吉星派对 Android 模组直装器。使用 **Shizuku 或 root**，对已匹配的游戏缓存安装加载补丁，保留官方游戏 APK 和签名。支持备份、恢复、模组启停和触屏操作。

**当前版本：0.5.0 渠道兼容测试版。** 本项目是独立适配项目，不是游戏官方或上游 CesiumLoader 的官方 Android 发布。

[下载 0.5.0 测试版 APK](https://github.com/Aperfish/CesiumLoader-Android-Direct/releases/tag/v0.5.0) · [构建方法](docs/BUILD.md) · [适配范围](docs/COMPATIBILITY.md) · [实现原理](docs/ARCHITECTURE.md)

## 安装使用

1. 安装官方游戏并完成资源下载，随后完全退出游戏。
2. 安装 Release 中的工具 APK。
3. 无 root 时启动 Shizuku，并授权本工具；有 root 时选择 root 后端并在 su 管理器中授权。
4. 勾选模组，点击“一键安装”。已知资源使用精确差分；0.5.0 默认开启“实验性强制兼容”，可尝试未收录的渠道资源，见下文。两种路径都备份本渠道原版缓存，再复制模组。
5. 启动游戏，等待游戏就绪。点击左侧可拖动的头像入口，左栏选择 Mod，右栏操作；两栏均可翻页。

更新安装工具后，需要退出游戏并再次点击“一键安装”，才会更新游戏目录中的 DLL。仅覆盖安装工具 APK 不会更新游戏里的模组。

## 0.5.0 渠道兼容实验

`com.feimo.astralparty` / `com.feimo.jxpd` 及其点分隔渠道后缀共用识别与安装。好游快爆包 `com.feimo.astralparty.haoyou` 在旧版已经能被识别；“资源版本未收录”是整份缓存未匹配，不是包名未匹配。

开启“实验性强制兼容”后，安装器解析 UnityFS（无压缩、LZ4/LZ4HC）和序列化资源，定位 `AstralParty.Runtime.dll`：运行程序集命中内置样本时使用对应补丁版本；未命中时，按程序集长度选择最接近的 3.3.0 基准，替换运行程序集。其他对象内容保留，重新计算对象偏移和文件长度，并重建缓存。关闭此开关保留严格模式；已安装的实验缓存仍支持读取状态、重装、配置和恢复。

这是运行程序集替换，不是对任意版本自动生成等价补丁。未知代码使用基准可能丢失渠道特有逻辑，出现登录失败或运行错误。加密缓存、不支持的资源格式和不兼容游戏版本不保证可用。**没有好游快爆资源样本或设备，尚未进行该渠道实测；不能宣称所有渠道通用。** 出现问题时完全退出游戏，点击“恢复原版缓存”。所有 30 项模组仍包含在本版中。

## 触屏功能

- **变速**：在悬浮窗选择变速模组，使用 1–10x 预设、加减和 1x/记忆切换。使用 Unity 时间倍率，系统时钟保持原速；每次游戏启动保持 1x。
- **自由相机**：双指纵滑或捏合缩放，横向平移不旋转；悬浮窗可恢复、拉近、拉远镜头。
- **其他入口**：HUD 显隐、角色半透明、刷怪预报、商店看板、快捷购买和 PVE 面板。
- **回合提醒**：游戏内文字提醒，不切换后台应用。

悬浮窗接入 [TenkinMori 的 AndroidApi](https://github.com/TenkinMori/CesiumLoader-Android-MOD)，保留头像、左侧模组与右侧功能结构；当前免改包方案使用 FairyGUI 作为窗口宿主，不需要系统悬浮窗权限。

## 已验证与限制

- 当前收录 3.3.0 的四份精确资源签名。关闭实验兼容时，未知资源和较新的未知缓存会被拒绝；实验模式允许解析、重建未收录缓存。两种模式都拒绝运行中写入及已识别的原生加载器叠加。
- 国服、可识别渠道后缀可尝试实验安装；未验证所有渠道，不含日服。

退出游戏后可在工具中保存启用项，或点击“恢复原版缓存”。恢复只针对工具已识别的缓存，保留配置、日志和备份。

## 源码与负载

仓库包含 Java 安装器、C# 安卓 SDK 适配、触屏 Mod、二进制适配工具和测试。**不提交游戏原始资源、个人日志、构建工具或签名私钥。**

原目录内 27 个 Mod 通过本地输入导入，另保留 NoBot，新增 AndroidControlsMod 和 CesiumOverlayMod，共 30 项。SpeedPerfProbe 没有 DLL，不计入。皮肤、音效替换仍需对应方案素材。

仅重建 Java 安装工具时，可从已发布 APK 提取经 SHA-256 校验的离线负载。重新生成 SDK、Mod 或游戏资源补丁则需要本地匹配的游戏资源、PC Mod 和 Bootstrap 输入。完整步骤见 [BUILD.md](docs/BUILD.md)。
