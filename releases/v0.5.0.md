## 0.5.0 测试版

本版新增渠道资源实验兼容，并移除双指横滑旋转。Shizuku/root 直装方式不修改游戏 APK，保留全部 30 项 Mod、悬浮窗及 1–10x Unity 变速控制。

### 更新内容

- 默认开启“实验性强制兼容渠道资源”。包名支持 `com.feimo.astralparty`、`com.feimo.jxpd` 及点分隔渠道后缀，包括 `com.feimo.astralparty.haoyou`。
- 未收录整份缓存时解析 UnityFS 和 TextAsset；内部运行程序集匹配时使用对应补丁，未匹配时按程序集大小选择最接近的内置 3.3.0 基准，替换运行程序集并重建缓存。其他程序集内容保留。
- 实验安装保留本渠道原版备份，支持状态读取、Mod 启停、重装、中断恢复和精确恢复原版。
- 自由相机只保留双指纵滑与捏合缩放，移除双指横向平移旋转；面板继续提供拉近、拉远及恢复镜头。
- GitHub Actions 校验并上传已签名 APK；无需向仓库上传签名私钥。

### 安装

1. 覆盖安装本版工具 APK，完全退出游戏。
2. 启动并授权 Shizuku，或选择 root 后端并在 su 管理器中授权。
3. 选择 Mod；需要尝试渠道资源时保持“实验性强制兼容”开启，点击“一键安装”。仅更新工具 APK 不会更新游戏目录中的 SDK/Mod。
4. 启动游戏测试；出现问题时完全退出游戏，在工具中点击“恢复原版缓存”。

### 验证与限制

离线验证通过：568 项既有安装事务断言、21 项渠道兼容断言、25 项手势与倍率断言。两种构造渠道缓存通过 UnityPy 独立解析，其余 18 个 TextAsset 内容不变。APK v2/v3 签名通过，签名证书与 0.4.0 相同。

**好游快爆服尚未实测，不保证所有渠道或游戏更新兼容。** 未知代码使用 3.3.0 基准可能影响渠道特有逻辑、登录或运行。暂不支持加密/LZMA 缓存，不允许与已识别的原生加载器改包叠加安装。皮肤、音效替换需要对应素材。
