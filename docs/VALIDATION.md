# 构建验证

## 0.5.0 渠道兼容实验

- 修改前运行 `tests/test-channel.py`：同一程序集仅改变 UnityFS 打包方式，即触发旧版 `supported: false` / 资源版本未收录。这复现同类拒绝条件，不是好游快爆实际缓存复现。
- 修改后原有 568 项安装事务断言通过。
- 21 项新增断言覆盖四份原始 LZ4HC/对齐缓存解析、内部程序集匹配、未知程序集最接近基准选择，以及渠道安装、状态、配置、重装、中断恢复和精确恢复原版。
- 渠道事务运行于 `-Xmx256m` Java 堆限制下；两种生成缓存均通过 UnityPy 独立解析，其余 18 个 TextAsset 内容逐字节一致，包括人为添加的渠道专有标记。
- APK v2/v3 签名验证通过。本版未安装到手机或模拟器，未验证好游快爆登录、加载入口及玩法。
- 按用户最新要求移除双指横滑旋转，保留纵滑和捏合缩放。25 项触屏/倍率逻辑断言通过，包含横向平移、大幅横向平移不旋转、纵滑、捏合、UI 避让、换指及抬指保护。四份 SDK 和 AndroidControls 已重编译进负载。

## 0.4.0 发布校验

独立源码目录完成完整负载生成与 APK 构建。完整重建负载内所有解压文件与发布 APK 一致；ZIP 时间戳造成容器摘要不同。使用发布负载重建 Java 后，classes.dex、AndroidManifest.xml、assets/payload.zip 和 assets/mod-list.json 与发布 APK 逐字节一致。签名封装和时间戳使整个重建 APK 的摘要不同。

- 四份缓存补丁目标 SHA-256 与发布配置一致。
- 安装事务：568 项断言通过，包括旧版迁移测试。
- API 注册与路径：13 项断言通过。
- 手势和倍率所有权：25 项断言通过。
- 主线程帧泵：主线程调用及仅订阅路径都通过，每帧恰好一次 Update/LateUpdate。
- APK v2/v3 签名验证通过。
